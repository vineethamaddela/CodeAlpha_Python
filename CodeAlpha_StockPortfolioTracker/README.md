# 📈 Stock Portfolio Tracker

## Description
This project is a simple Stock Portfolio Tracker developed using Python. It calculates the total investment value based on user-entered stock names and quantities using a predefined dictionary of stock prices.

## Features
- User input for stock names and quantities
- Hardcoded dictionary for stock prices
- Calculates total investment value
- Saves the result to a text file
- Simple command-line interface

## Technologies Used
- Python 3

## Concepts Used
- Dictionary
- Loops
- Input / Output
- Arithmetic Operators
- File Handling

## How to Run

1. Open the project folder.
2. Run the program:

```bash
python stock_portfolio.py
