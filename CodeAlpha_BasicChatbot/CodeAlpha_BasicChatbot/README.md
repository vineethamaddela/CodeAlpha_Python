# 🤖 Basic Chatbot

## Description
This is a simple rule-based chatbot developed using Python. It responds to basic user inputs with predefined replies.

## Features
- Responds to "hello"
- Responds to "how are you"
- Exits on "bye"
- Uses functions, loops and if-elif statements

## Technologies Used
- Python 3

## Concepts Used
- Functions
- Loops
- If-elif-else
- Input / Output

## How to Run

```bash
python chatbot.py
```
